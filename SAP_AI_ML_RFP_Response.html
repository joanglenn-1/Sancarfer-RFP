Q1Can you provide a detailed overview of your AI and ML platform's architecture?✅ Full

SAP AI Core is a cloud-native, Kubernetes-based MLOps service on SAP BTP — the unified execution and lifecycle management layer for enterprise AI.

  • Pipeline Orchestration: Argo Workflows manages DAG-based training, batch inference, and multi-step AI pipelines with parallel execution, retry logic, and configurable resource scheduling per step.

  • Multi-Cloud Infrastructure: Runs within SAP BTP's managed Kubernetes clusters across AWS, Azure, and GCP in 20+ global regions — customers choose region for data residency without changing any AI API calls.
  • Enterprise Integration: Native connectors to SAP S/4HANA, SAP Datasphere, SAP Integration Suite, and Joule provide seamless AI embedding into existing SAP business processes and applications.

Q11What security measures does your platform implement to protect data both at rest and in transit?✅ Full

SAP AI Core operates within SAP BTP's enterprise security perimeter with defence-in-depth encryption covering all data states and network communication channels.

  • Encryption at Rest: All stored data — model artifacts, training datasets, pipeline logs, and configuration files — is encrypted using AES-256 via the underlying cloud provider's managed encryption service (AWS KMS, Azure Key Vault, GCP KMS).
  • Encryption in Transit: All network communication uses TLS 1.3 minimum — between client applications and AI Core APIs, between Kubernetes pods, and to/from object storage.
  • Network Isolation: AI Core workloads run within SAP BTP's private Kubernetes network with no direct public internet exposure. Egress traffic is controlled via network policies.
  • Secrets Management: SAP Credential Store manages API keys, connection strings, and secrets used in pipeline containers — no secrets are embedded in Docker images or workflow definitions.
  • Penetration Testing: SAP BTP and SAP AI Core undergo regular third-party penetration testing, with findings tracked and remediated per SAP's security vulnerability management process.
